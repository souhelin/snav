# Snav Browser

Snav é um navegador leve, simples e ágil para o uso diário. Ideal para quem quer abrir a internet rápido, sem travar e sem complicação.

---

## Imagens do App

![Logo do Snav](image/logo.png)  

---

## Funcionalidades

- Navegação rápida e leve  
- Interface simples e intuitiva  
- Ideal para uso diário sem travar o dispositivo  

---

## Como usar

1. Baixe o APK na seção **Releases** do repositório.  
2. Instale no seu dispositivo Android.  
3. Abra o Snav e comece a navegar.

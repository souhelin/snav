# Símbolos do Material

Os drawables `ms_*.xml` são derivados dos SVGs oficiais **Material Symbols
Rounded**, 24 px, do repositório [google/material-design-icons](https://github.com/google/material-design-icons),
distribuídos sob a [licença Apache 2.0](MATERIAL_SYMBOLS_LICENSE.txt).
A versão de referência é o commit `10ecc14790612ca8fd164e3f4ffe9c16fc50d5b7`.
Os caminhos dos SVGs são mantidos; apenas o `viewBox` é transladado para o
sistema de coordenadas do VectorDrawable do Android. As imagens de sites são
favicons dos próprios sites, não símbolos de interface. Quando não há favicon,
o Snav usa o símbolo oficial `language`.
